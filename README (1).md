# Coraline Interactive Guide Chapter 01

An interactive study guide for Year 7 students exploring Chapter 1 of Neil Gaiman’s *Coraline*.

## Learning activities

- Explore settings and characters in a 3D environment.
- Investigate mood, atmosphere and characterisation.
- Reflect on the door and the dream rats, including their song.
- Practise vocabulary, including **flyblown** and **distorted**.
- Complete reading questions and interactive cards, with hints and model answers.

## Open the guide

Open the published GitHub Pages website link in your browser. On a computer, use the arrow keys or WASD to move. On a touch screen, use the on-screen controls. Select characters and clues to open activities.

## Publish with GitHub Pages

1. Upload `index.html` to the main folder of this repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select **main** and **/(root)**, then click **Save**.
5. After deployment completes, return to **Settings → Pages** and select **Visit site**.
6. Share the published website link with students through Google Classroom.

The guide contains its scripts, styling and images within `index.html`. No additional game files or installation are required. This README provides instructions and is not required to run the guide.

## Compatibility

The guide uses JavaScript and WebGL for its 3D environment. iPhone and iPad compatibility has not yet been confirmed. Test the published website on the students’ devices before assigning it.
